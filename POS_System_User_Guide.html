2. Installation & Setup

2.1 Clone the Repository

git clone https://github.com/joshkirui/supermarket-pos.git
cd supermarket-pos

2.2 Install Backend Dependencies

npm install

2.3 Install Frontend Dependencies

cd frontend
npm install
cd ..

2.4 Build the Backend

npx nest build

2.5 Start the System

Open two terminals in the project folder:

TerminalCommandWhat It Does
Backendnode dist/main.jsStarts API server on port 3001
Frontendcd frontend && npx vite --hostStarts React app on port 5173
Tip: If PowerShell blocks scripts, run this first:
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

Open your browser to http://localhost:5173

3. Database Configuration

3.1 PostgreSQL Setup

Edit the .env file in the project root:

DATABASE_URL="postgresql://username:password@localhost:5432/pos_db"
JWT_SECRET="your-secret-key-here"
PORT=3001

3.2 Run Migrations

npx prisma migrate deploy

3.3 Seed the Database

node prisma/seed.js

This creates: permissions, roles, admin user, 12 products, payment methods, and categories.

3.4 Create Supermarket Accounts

node create-accounts.js

This creates all user accounts and sample customers listed in Section 4.

6. POS Terminal (Barcode Scanning)

This is the main screen for processing sales. Navigate to Sales → POS Terminal.

6.1 Scanning Items

  1. The barcode input is always focused — no need to click it
  2. Point your barcode scanner at a product barcode
  3. The scanner types the barcode number and presses Enter automatically
  4. The product appears in the cart table below
  5. Product name, SKU, price, and quantity are shown

6.2 Manual Entry

  1. Click the barcode input field
  2. Type the barcode number manually
  3. Press Enter

6.3 Adjusting Quantities

  • Click + to increase quantity
  • Click − to decrease quantity
  • Click the trash icon to remove an item

6.4 Completing a Sale

  1. Check the Order Summary panel on the right
  2. Verify Items count, Subtotal, VAT (16%), and Total
  3. Click Complete Sale
  4. Select payment method (Cash / M-Pesa / Card)
  5. Confirm payment
  6. Receipt is generated and saved
VAT: All prices include 16% VAT as required by Kenya Revenue Authority (KRA).

7. Products Management

Navigate to Products in the sidebar.

7.1 View Products

  • Products displayed as cards with name, SKU, category, price, and stock level
  • Use the search bar to filter by name, SKU, or barcode
  • Click any product to add it to the current cart

7.2 Add a New Product

  1. Click Add Product button (top right)
  2. Fill in the form:
    • SKU * — Unique stock keeping unit code (e.g., MILK-003)
    • Product Name * — Full product name (e.g., Fresh Milk 1L)
    • Barcode — EAN-13 barcode number
    • Selling Price — Price in KES
    • Cost Price — Your purchase cost in KES
    • Initial Stock — Starting quantity
    • Reorder Level — Minimum stock before alert (default: 10)
  3. Click Add Product

8. Inventory Management

Navigate to Inventory in the sidebar.

8.1 View Stock Levels

  • All Stock tab — shows all products with current stock levels
  • Low Stock tab — shows only products below reorder level (amber alerts)
  • Search by product name or SKU

8.2 Adjust Stock

  1. Click Adjust Stock button
  2. Select the product from the dropdown
  3. Choose adjustment type:
    • Restock — New delivery from supplier
    • Adjustment — Stock count correction
    • Damage — Damaged/expired items
    • Return — Customer returns
  4. Enter the quantity
  5. Add a reason (e.g., "Supplier delivery - invoice #1234")
  6. Click Adjust

8.3 Transfer Stock

  1. Click Transfer button
  2. Select the product
  3. Enter the quantity to transfer
  4. Set the From Terminal and To Terminal IDs
  5. Add a reason (e.g., "Inter-branch transfer")
  6. Click Transfer

10. Customers & Loyalty

Navigate to Customers in the sidebar.

10.1 View Customers

  • Table shows Name, Phone, Email, and Loyalty Points
  • Search by name, phone, or email

10.2 Add a Customer

  1. Click Add Customer
  2. Enter Phone Number (required — used as unique ID)
  3. Enter Name and Email (optional)
  4. Customer is saved and can earn loyalty points on future purchases

10.3 Loyalty Program

  • Customers earn 1 point per KES 1 spent (configurable)
  • Points are auto-calculated on each sale
  • Tier upgrades: Bronze → Silver (KES 10,000+) → Gold (KES 50,000+)
  • Points can be redeemed at checkout to discount the total

14. M-Pesa Integration (STK Push)

14.1 How It Works

  1. Cashier selects M-Pesa as payment method at checkout
  2. Customer enters their M-Pesa phone number
  3. System sends an STK Push to the customer's phone
  4. Customer enters their M-Pesa PIN on their phone
  5. Payment callback confirms success or failure
  6. Sale is completed and receipt generated

14.2 Setup Steps

  1. Register at https://developer.safaricom.co.ke
  2. Create an app and get Consumer Key + Secret
  3. Set up a Paybill or Till Number
  4. Configure the callback URL in both Safaricom portal and POS Settings
  5. Enter all credentials in Settings → M-Pesa Settings
Note: M-Pesa requires a Safaricom Lipa Na M-Pesa sandbox for testing. Use test credentials before going live.

15. Barcode Scanner Setup

15.1 Compatible Scanners

Any USB barcode scanner that works as a keyboard input device (HID mode) is compatible. Popular models:

  • Honeywell Voyager 1200g
  • Zebra LS2208
  • Datalogic QW2520
  • Any affordable 1D barcode scanner from Jumia/Kilimall

15.2 Setup

  1. Plug the scanner into a USB port
  2. The scanner should be in keyboard/wedge mode (default for most scanners)
  3. Open the POS Terminal (Sales page)
  4. The barcode input is always focused — just scan directly
  5. The scanner reads the barcode, types the numbers, and presses Enter
  6. The product is automatically added to the cart

15.3 Testing Your Scanner

Open Notepad, scan a barcode. If numbers appear, the scanner is working correctly.

15.4 Barcode Format

  • The system uses EAN-13 barcodes (13 digits)
  • Sample barcodes in the seed data:
    • 6161100100011 — Fresh Milk 500ml
    • 6161100100028 — Fresh Milk 1L
    • 6161100300028 — Coca-Cola 500ml
    • 6161100600011 — White Bread 400g

16. Troubleshooting

ProblemSolution
Blank white screenClear browser localStorage, refresh. Make sure Vite is running.
"Invalid credentials" on loginCheck username/PIN. Default: admin / 1234. Ensure backend is running on port 3001.
"No product found" when scanningCheck if the barcode is in the database. Add product with matching barcode.
Crashes on page navigationRefresh the page. Check browser console for errors.
Backend won't start (port in use)Run netstat -ano | findstr :3001, kill the process, restart.
PowerShell blocks npxRun Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass first.
Database connection errorCheck .env file. Ensure PostgreSQL is running. Verify username/password.
"Argument skip is missing" errorEnsure backend is rebuilt: npx nest build
Scanner not adding itemsEnsure POS Terminal tab is active. Check if the scanner types into Notepad.
M-Pesa payment not going throughCheck M-Pesa credentials in Settings. Ensure callback URL is accessible.
