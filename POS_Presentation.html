M-Pesa Integration

How STK Push Works

1. Cashier selects M-Pesa

Payment method at checkout

2. Customer enters phone number

Safaricom registered number

3. STK Push sent

Prompt appears on customer's phone

4. Customer enters M-Pesa PIN

Confirms payment on their device

5. Callback received

System confirms payment instantly

6. Receipt generated

Sale completed, stock updated

Why M-Pesa Matters

  • 73% of Kenya's GDP flows through M-Pesa
  • 33+ million active users in Kenya
  • Average supermarket: 35% M-Pesa payments
  • Zero cash handling risk for large amounts

Technical Details

  • Lipa Na M-Pesa API integration
  • Idempotent callback handling
  • Automatic retry on timeout
  • Transaction ID verification
